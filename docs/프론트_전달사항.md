# 프론트 전달사항

이 문서는 프론트 저장소로 옮겼어요. 최신본은 아래에 있어요.

→ [edu-AX/front-end · docs/프론트_전달사항.md](https://github.com/edu-AX/front-end/blob/main/docs/%ED%94%84%EB%A1%A0%ED%8A%B8_%EC%A0%84%EB%8B%AC%EC%82%AC%ED%95%AD.md)

## 요약

- 화면은 `edu-AX/front-end`, API와 도메인 로직 원본은 `edu-AX/back-end`(이 저장소)에 있어요.
- 프론트는 `NEXT_PUBLIC_API_BASE_URL`(기본값 `http://localhost:3001`)로 이 저장소의 `/api/chat`, `/api/upload/*`를 불러요.
- 프론트가 브라우저에서 바로 쓰는 계산 코드·데이터 15개 파일은 프론트에서 `npm run sync:backend`로 이 저장소의 특정 커밋에서 받아 가요.
  - 어느 커밋인지는 프론트의 `backend.lock.json`에 적혀 있어요.
  - **그 파일들은 여기(백엔드)에서만 고치세요.**
